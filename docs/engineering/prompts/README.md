# Working Prompts

These editable English outlines support the owner's natural-language steering with any assistant. Replace placeholders with current facts. They do not register tool-specific commands, start an automation, install a plugin, or bypass project permissions.

| Prompt | Purpose |
| --- | --- |
| [Start an issue](start-issue.md) | Set the bounded Goal, evidence plan, and authorization. |
| [Steer the active task](steer.md) | Incorporate a correction without restarting unrelated work. |
| [Repair a failure](repair.md) | Turn observed feedback into a discriminating check and scoped fix. |
| [Resume after interruption](resume.md) | Recover the current state and next action without inventing progress. |
| [Review the final version](review.md) | Obtain an independent, version-bound verdict. |

Short natural-language alternatives work: “Continue issue #N from its checkpoint”, “Keep the scope; fix the failed shutdown test”, or “Inspect only; do not modify anything.” Preserve the owner's actual intent over template defaults. Publication must already be authorized; never infer merge approval from successful checks.
